# Remote Gaming Android Agent (APK Project)

This is the native Android project that streams 60 FPS gameplay to your Chromebook and receives ultra low-latency touch and gamepad controls via WebRTC.

## How to Build & Install:
1. Open this unzipped folder in **Android Studio** (Koala / Ladybug or newer).
2. Connect your Android phone via USB with **USB Debugging** enabled.
3. Click **Run 'app'** or select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Launch the app on your phone, note the **6-digit Pairing Code**, and enter it on the Chromebook Web Console!
